# FotoCesta

Lista de la compra por fotos y voz, con presupuesto por supermercados.

**Descargar la app:** en esta página, entra en *Releases* (a la derecha) y pulsa **FotoCesta.apk**.
Enlace directo a la última versión: `releases/latest/download/FotoCesta.apk`

Cada cambio que se sube a la rama `main` compila una APK nueva automáticamente (pestaña *Actions*).
